# پوشه PUUD-file — نسخه کپی‌شده برای نگهداری سابقه

این پوشه در مخزن به‌عنوان نسخه کمکی/قدیمی نگهداری شده است. در موجودی فعلی مخزن، فایل‌های main.py و main.py.txt با فایل PUDD/main.py یکسان‌اند (شناسه محتوای Git آن‌ها یکسان ثبت شده است).

**این پوشه را با یک پیاده‌سازی مستقل یا نسخه جدید الگوریتم اشتباه نگیر.** تا زمانی که تفاوت مستندی پیدا نشده، فایل اصلی برای بررسی کد مسیر PUDD/main.py است.

برای ادامه کار:
- راهنمای اصلی پروژه: [README.md](../README.md)
- راهنمای کد PUDD: [PUDD/readme.md](../PUDD/readme.md)
- مقاله PUDD تبدیل‌شده: [4. PUDD.md](../markit_concept_drift/4.%20PUDD.md)

فایل‌ها حذف نشده‌اند تا سابقه مخزن حفظ شود. پیش از استفاده از هر نسخه کپی‌شده، تفاوت آن را با فایل اصلی بررسی کن.
