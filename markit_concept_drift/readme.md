## Conversion quality note

Some Markdown files contain large embedded base64 images and inconsistent heading styles. This may make automated navigation noisy. Before relying on a figure, formula, or method-defining table, compare it with the original PDF. Do not delete image payloads until important figures/tables have been checked.
